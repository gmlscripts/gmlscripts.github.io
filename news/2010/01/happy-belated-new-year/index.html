January 10, 2010Happy (Belated) New Year!

Yeah, yeah, I'm late. I even toyed with the idea of forging the date of this post, but I think I've had enough of that rebuilding the forum, and hacking my website is so 2009*.

The final release version of Game Maker 8 was released a few weeks ago. It's been given a fresh coat of paint and features some drastic improvements in the sprite and script editors. There are also many significant changes to GML in this version and that means there are several scripts that do not work with it. Please help me hunt them down and post about them here in this Script Alumni topic.

/forums/viewtopic.php?id=1624

Game Maker isn't the only thing getting an upgrade. GMLscripts.com is going to have to grow to keep up with GM8. Many things could work better here. I'm sure you can think of a few. Please join me in discussing them and the future of GMLscripts.com this Community topic.

/forums/viewtopic.php?id=1708

In non-Game Maker news, ChevyRay's FlashPunk has just been released. If you're a GM user with a hankering to try some Flash game programming, I think you'll find some welcome features in the FlashPunk game library. Check it out.

http://www.flashpunk.net/
