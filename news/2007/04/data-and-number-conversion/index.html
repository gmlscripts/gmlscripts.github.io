April 5, 2007Data and Number Conversion

Several new scripts have been added for converting numbers and data into different formats. There are scripts for base conversion, such as decimal to hexadecimal or binary, and there are scripts for data encoding and decoding, such as encoding a string of bytes to Base 64 (RFC 3548) or converting a real number to an 8-byte double and back again.
