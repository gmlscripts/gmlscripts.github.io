August 11, 2008GMLscripts.com 2.0

Whew.

OK, obviously a major update. If things look screwy, clear your browser cache and/or refresh the page. Here's what's new:

  • New Layout - Nicer looking by far, I think, and stretchy, too. It does require a wider screen, but nothing that isn't supported by a typical system.

  • Sidebar Navigation - The GMLscripts.com script index is conveniently placed on the right side of every page.

  • Forum Integration - You can log into your account from GMLscripts.com or the GMLjoint forums. Some site features are disabled if you are not logged in.

  • News Comments - Because the GMLscripts.com news system is now part of the forum, you can easily post public comments on any updates.

  • GML Highlighter - Highlight your GML code for posting on forums or in web pages. Several output options available.

This update was surprisingly long in coming. It was basically ready and supposed to go up about six months ago to coincide with the site's 1st anniversary. Then a funny thing happened. I was asked by GMC staff to be a moderator over there. Then a stupid thing happened. I accepted. That's when all my "Game Maker time" went out the window. Changes are being made to correct that and I'll finally be able to get back to administering GMLscripts.com properly.

Sorry, no new scripts right now. Looks like tomorrow never came.

August 9, 2008Big changes afoot

OK, it may only look like a skin change but there is more going on here than meets the eye. GMLscripts.com and GMLjoint.com are in the process of becoming more closely integrated. You should notice the forum coming up under the GMLscripts.com domain now. If I didn't screw up royally, a GMLjoint.com URL automatically redirected you to there. I really didn't want to make the domain change but it was necessary to enable some upcoming features.

Another change I've made is to the registration system. Some of you may have seen spam popping up here and in the RSS feed. I've added a CAPTCHA system to try and thwart that. It's a bit simplistic but we'll see how it goes.

More news to come ...

Bah! CAPTCHA has been disabled until my web host can work out some problems with their session management.

February 12, 2008Download ALL Scripts on GMLscripts.com

You can now download every script in the GMLscripts.com archive with one click. The link is on the script index page and should always be up to date.

/script/index

I'm hoping that by making it easy to get all of the scripts I can reduce the number the badly behaved bots trying to mirror the site every week. I don't expect it to work, so I'm also ramping up my bot countermeasures. Any suspicious behavior will result in immediate banination. I'm not outlawing spider bots, just naughty ones. Anyone respecting the robots.txt file will not have any problems.
